# Muhasabah

Single-user self-task tracking dashboard built with Next.js, Prisma, NeonDB, and Vercel.

## Setup

1. Copy `.env.example` to `.env`.
2. Run `npm install`.
3. Run `npx prisma migrate dev`.
4. Run `npm run setup`.
5. Optionally run `npm run seed`.
6. Run `npm run dev`.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run test`
- `npm run test:e2e`
- `npm run setup`
- `npm run seed`
